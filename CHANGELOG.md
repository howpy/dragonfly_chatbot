# Changelog

## 0.1.0 — 2026-10-21

- Installable DeepSeek Harness bundle with three read-only knowledge tools.
- Local BM25 retrieval, Chinese term aliases, exact API/title terms and strict version filters.
- Evidence IDs with source and line coordinates; bounded excerpts and full evidence reads.
- Bundled first-party Prototype Apps manuals and original technical notes.
- Explicit local Help / Python source import, corpus merge, search and status CLI.
- Domain-specific answer instructions without replacing the host's complete prompt.
- Import boundary, CLI, retrieval, plugin and real Harness lifecycle verification.

Initial release: no vector embeddings, reranker, hosted knowledge service or end-to-end
LLM accuracy claim. Official Help/source coverage depends on local imports.
